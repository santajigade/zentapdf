This Gantt chart template in Excel turns a simple task list into a project plan with a timeline. You type each task, its owner, the start date, the number of days and how much is done, and the sheet fills in the end date, the status and a coloured bar across 16 weeks. It prints on one landscape page, so you can share the plan in a meeting or as a PDF.

How to use this gantt chart template excel

  1. Download the Excel file and open it in Microsoft Excel, Google Sheets or LibreOffice Calc.
  2. Type the project name in the top line and the project manager name in the box below it.
  3. Enter the Project start date. The 16 week timeline starts from the Monday of that week.
  4. Choose Yes or No in Working days only. Yes skips Saturdays and Sundays when the end date is worked out.
  5. Replace the sample tasks with your own. For each task type the owner, start date and number of days.
  6. Update % done as work moves ahead, for example 50% for a task that is half finished.
  7. Check the Status column and the bars. Late tasks turn red so you can follow up quickly.
  8. Print the sheet or save it as PDF to share the plan with your team or client.

What is inside the file

One sheet called Gantt with room for 30 tasks. The columns are #, Task, Owner, Start, Days, End, % done and Status, followed by 16 week columns. Each week column shows the month and the Monday date at the top.

The top of the sheet shows the project start, the project end (the latest end date of all tasks), today's date, the overall % done and the number of late tasks. Overall % done is weighted by days, so a long task counts more than a short one. A small legend at the bottom explains the colours.

How the bars and status work

The bars are made with conditional formatting, not with a chart, so there is nothing to redraw. A week cell turns light blue when the task runs during that week. The done part of the task is shaded dark blue based on % done. If the end date has passed and the task is not 100% done, the whole bar turns red and the status says Late.

Status is worked out from today's date: Not started, In progress, Late or Done. The current week is highlighted in amber in the header, so you can see at a glance where the project should be.

Working days and holidays

When Working days only is set to Yes, the End date uses the WORKDAY function, which skips Saturdays and Sundays. It does not know your public holidays, because these differ by country, state and company. If a holiday falls inside a task, add one more day to that task. Set it to No if your team works every day or you plan in calendar days.

Tips for best results

  • Break big jobs into tasks of 2 to 10 days so progress is easy to judge.
  • Give every task one owner. Shared tasks tend to slip.
  • Update % done once a week, before your team meeting.
  • Keep the first sample plan as a copy and start each new project from a fresh download.
  • If a task cannot start until another ends, set its start date to the day after the earlier task ends.

Frequently asked questions

Does this Gantt chart work in Google Sheets?

Yes. Upload the file to Google Drive and open it with Google Sheets. The formulas, the Yes or No drop-down and the coloured bars all work there.

Can I show more than 16 weeks?

The print layout is set for 16 weeks on one page. For a longer project, move the Project start date forward to see later weeks, or copy the last week column to the right and widen the print area.

Can I add more than 30 tasks?

Yes. Insert rows inside the task table, above the last task row, and copy the formulas in the #, End and Status columns down. The bar colours follow the new rows.

Does it link tasks to each other?

No. Each task has its own start date. To show that one task follows another, type a start date after the end date of the earlier task. Changing one task does not move the others.

Does it use macros?

No. The file has only normal formulas and conditional formatting, so it opens safely and nothing needs to be enabled.
